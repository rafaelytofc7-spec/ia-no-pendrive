IA no Pendrive

    Configurações

    Servidor local

    Use o INICIAR do seu sistema no pendrive. No celular, digite o endereço que aparece na janela do PC (ex.: http://192.168.0.10:8080).

    Modelo dentro do navegador

    Roda 100% no aparelho, sem internet. Escolha um arquivo .gguf pequeno (até ~1,5 GB; recomendado: Qwen3.5-0.8B-Q4_K_M.gguf da pasta modelos do pendrive).

    ou baixe da internet (fica salvo no navegador):

    Hugging Face

    Crie um token em huggingface.co → Settings → Access Tokens (permissão “Make calls to Inference Providers”). O token fica salvo só neste navegador.

    API compatível com OpenAI

    Ex.: OpenRouter (https://openrouter.ai/api), Groq (https://api.groq.com/openai), Ollama (http://localhost:11434), LM Studio (http://localhost:1234).
